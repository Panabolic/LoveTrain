# 2026-10-04 자동 공격, 가속/질주, 살점 창조, 연료 체력

## 사용자 범위
세 항목 모두 구현. 추가 지시: Shift를 놓으면 1초간 현재 속도를 유지한 뒤 기본 속도로 서서히 감속.

## 변경
- Gun: Playing/Boss에서 자동 발사. 조준 입력은 기존 GunPivot 유지. 이벤트/정지/사망/전환에서는 발사 중단.
- Train / TrainDriveState: 기본 속도 320, 일반 최대 460, 가속/감속 70/초. Shift 최대 도달 시 5초간 최대의 1.5배 질주, 피격 무효. 지속 홀드만으로 연속 질주 불가; 해제 후 재가속 가능. 질주 종료는 일반 최대로 돌아오고 해제 1초 뒤 감속.
- 연료 100: 기본 소모 0.25/초, 기본 대비 속도 상승량에 비례해 증가, 질주 10/초. 피격은 연료만 감소. 연료 0이면 사망. 기존 속도 이벤트는 속도만 조절. HealPercent/GiantMaw는 연료 회복.
- TrainLevelManager / RunPartEconomy: 기존 GainExperience 진입점을 살점 지급으로 전환. 자동 레벨업/선택창 중단. 기존 레벨/이벤트 API는 호환 유지.
- F: 부품 창조 창을 일시정지 큐로 열고 랜덤 미보유 부품 하나 제안. F/클릭 확정 시 50 살점 지불, 매 창조 후 비용 +25. R/버튼 재추첨 10. 취소/재개로 무료 재추첨되지 않도록 미확정 제안 유지. 생성 비용을 남길 수 있을 때만 리롤 허용. 열기 프레임의 F가 확정으로 재사용되지 않음.
- Inventory: 머리/가운데/꼬리 각 3칸, 바퀴 공용 1칸. 중복 획득은 업그레이드하지 않으며 전용 UpgradeItemInstance 이벤트 경로는 유지.
- 랜덤 아이템 이벤트 보상은 요청 개수당 살점 50으로 전환. 특정 아이템 획득은 보유/공간 부족을 검증하고 실패 시 허위 획득/업그레이드나 null 접근 방지.
- FuelBarrel.prefab / FuelBarrel: 단순 픽셀 연료통 적. Junmo Spawner가 전투 20초마다 생성. 처치 시 연료 +20, 살점 +5. 정리/수명 만료에는 보상 없음. 초기 시각/충돌 컴포넌트는 Awake에서 생성하며 보상 중복을 막음.
- HUD: 오른쪽 살점 TMP 명시 연결, 기존 XP 바는 연료 비율, 기존 레벨 텍스트는 F 창조 비용/연료 표시. 속도 바늘은 질주 시 계기판 최대각을 넘어감.

## 검증
- 임시 csproj로 기존 Unity 참조 및 새 FuelBarrel까지 C# 컴파일: 오류 0, 경고 9 (retired serialized fields/level event 포함). Unity 생성 csproj는 수정하지 않음.
- 실제 소스에서 추출한 순수 주행/경제/인벤토리 메서드로 25개 .NET 행동 검사 통과: 가속, 해제 1초 경계, 감속, 기본속도 하한, 질주 초과속도/시간/소모, 일시정지, 홀드 재질주 방지, 재무장, 속도별 연료 증가, 부족/정확/음수 결제, 보상 오버플로, 중복/부위별/바퀴 용량/null.
- Junmo 1086개 문서 ID 중복 없음, 누락 로컬 fileID 없음. 살점 참조와 새 프리팹 script GUID 연결 확인.
- Unity Editor 연결 도구 사용 불가: 실제 Import/Play Mode, UI 렌더링, 적 충돌 및 전체 사망/보스/엔딩 흐름은 이번 검증에 포함되지 않음.

## 범위/제한
수치와 연료통 시각은 초기 기본값. 영혼 영구 성장, 전용 업그레이드 이벤트의 셀당 가격, 이벤트 전체 문구/조건 재설계는 이번 세 항목 범위에 포함하지 않음. 기존 StructureMemory 일부가 실제 없는 분리 클래스들을 서술하므로 현재 구현은 실제 파일을 기준으로 함.

## 시작 레버 입력 보완

사용자 추가 요청: Start에서는 왼쪽 마우스 버튼을 누르는 동안 발사하여 총알로 기존 StartObject 레버를 작동시킨다. Playing/Boss 자동 공격 및 나머지 상태 발사 차단은 유지한다. Gun.Update만 수정; 레버의 총알 충돌 → StartGame 경로 재사용. C# 컴파일 확인, 실제 플레이 미확인.

## 상대속도와 앞뒤 스폰 보정

사용자 승인: 가속할수록 앞쪽 증가/뒤쪽 감소, 살점 파밍 기회 보충. 실제 속도의 기본~일반 최대 구간을 0~1로 정규화하여 키를 놓은 1초 유예/감속 동안 비율도 자연스럽게 복귀한다.
- Train.RelativeWorldSpeed = max(0, 현재속도-기본속도) × relativeSpeedScale(0.02). Mob/FlyMob의 수평 이동에서 이 값을 뺀다. 기본속도 기존 이동 유지, 가속 시 앞쪽 접근 증가/뒤쪽 추격 감소 또는 밀려남. 질주 실제 초과속도에도 반영.
- Spawner 기본 몬스터 타이머: 최대 가속에서 1.75배. 전면 지점 가중치 1→4, 후면 1→0.25. 기본속도에서는 기존 지점별 균등 확률 유지. 비행 스폰 영역은 플레이어 x 기준 전후 분류. 후면 스폰 금지 플래그 준수. 엘리트는 전후 분포만 바꾸고 주기 유지; 보스/연료통/이벤트 지정 수량 및 주기 유지.
- 질주 스폰 보정은 최대 가속값으로 제한하여 과도한 몬스터 생성을 방지한다. 앞뒤 지점 수가 같으면 최대 가속에서 앞 약94%, 뒤 약6%; 기본 시간당 앞 스폰 약3.29배/뒤 약0.21배. 정확한 살점 수급 보장은 플레이 밸런스 검증 필요.
- 뒤로 밀려 이미 진입했던 화면의 왼쪽 여유 영역을 벗어난 일반/비행 몬스터는 DespawnWithoutExp 경로로 정리. 처치 보상 없음.
- 일반/엘리트 타이머는 스폰 중지 플래그를 따르도록 보완. 스폰 타이머 잔여 시간 보존.
- 검증: 기존 Assembly-CSharp 프로젝트 C# 컴파일 오류0. 실제 Unity 플레이/스폰 밀도/살점 수급은 미확인.

## 가속 보정 급변 완화 (현재 수치)

사용자 피드백: 몬스터 속도/스폰 빈도 급증 체감. 질주 때 상대속도 보정 2.8→7.4 즉시 변화, 정규화 가중치에 따른 전면 약94% 집중이 원인 후보로 확인됨.
- 몬스터 상대속도 목표는 실제 속도와 비례하되 보정값 변화율을 2 월드 단위/초로 제한. 질주 속도 자체와 초과속도는 유지. 사망/엔딩 초기화에서 보정도 초기화.
- 일반 스폰 빈도 보정: 가속비율 0/25/50/75/100%에서 1/1.0875/1.175/1.2625/1.35배. Junmo serialized 값도 명시적으로 1.35 설정.
- 전후 확률은 지점 수 기준 기존 전면 확률에서 최대80%까지 선형 보간. 앞뒤 수가 같으면 50/57.5/65/72.5/80%. 각 그룹 내 균등 확률, 누락 지점/null/후면 금지 처리 유지. 기존 4/0.25 가중치 필드는 제거.
- 기존 120초 단위 SpawnPhase의 종류/기본 간격 변화는 유지. 가속 보정과 별개로 진행 난이도는 계속 증가한다.
- C# 컴파일 오류0, 실제 Play Mode 체감은 미확인.
